# TWRP for LG D625 (`g2mv`)

The TWRP 3.1.1 device tree for the LG G2 Mini LTE (D625, NVIDIA Tegra 4i)
lives in its own repository:

**[android_device_lge_g2mv](https://github.com/chijure-android-system-development/android_device_lge_g2mv)**

Prebuilt images are published in this repository's releases. TWRP only boots
on a D625 whose bootloader has been patched as described in the
[main README](../README.md).
